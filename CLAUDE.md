# Thornlash: project notes for future sessions

This is an original gothic whip-action platformer. It began as a request for a *Castlevania*
remake, and all of its content is new; keep it that way (see `docs/DESIGN.md`). It runs in
Godot 4.7.2 at 320×224 with a fixed 60 Hz step. The hero is Corvin Ashdown and the final
boss is the Pale Margrave.

## Commands (Windows, Git Bash)

```bash
G="$HOME/Downloads/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe"
"$G" --headless --path godot --import
"$G" --headless --path godot --script res://tests/run_tests.gd --quit-after 1000000   # "TESTS 26/26 passed"
bash godot/tests/harness.sh                       # "HARNESS 0 failure(s)"; ONLY=regex filters checks
python tests/verify_audio.py                      # "AUDIO ok"
python godot/tests/mutation_core.py               # planted faults in the rules must all be caught
python godot/tests/mutation_harness.py            # planted faults in the app must all be caught
"$G" --headless --path godot --export-release "Windows Desktop" ../dist/Thornlash/Thornlash.exe
bash godot/tests/harness.sh "$G" --main-pack "E:/Claude Code/thornlash/dist/Thornlash/Thornlash.exe"
```

Screenshots need a window, so drop `--headless`:
`"$G" --path godot --audio-driver Dummy -- --script=new:classic,stage:3,boss,wait:60,shot:C:/abs/x.png`.

The harness commands are `new:style[:stage]`, `stage:n`, `block:id`, `boss`, `at:x:y`,
`hold/up/tap:action`, `key/keydown/keyup:K`, `pad/padup:btn`, `wait:n`, `set:opt:value`,
`give:x`, `hurt:n`, `killboss`, `toorb`, `dump`, `ents`, `menu`, `assets` and `shot:path`. An
unknown command prints `HARNESS unknown command`. Harness runs use `user://harness/`, which
starts empty and is kept apart from the player's saves.

## Architecture

- **Rules:** `godot/scripts/core/` (`game.gd`, `actors.gd`, `level.gd`) is pure data plus rules
  and uses no nodes. `Game.s` is one Dictionary. It is deep-copied for rewind and written with
  `var_to_str` for saves. Never keep game state in nodes.
- **App:** `godot/scripts/main.gd` holds the screens, menus, input map and rebinding, history,
  slots, options, vibration and harness. `view/render.gd` draws the state, `view/ui.gd` draws
  menus and overlays, and `view/audio.gd` plays sound.
- **Content** is read raw with FileAccess. Every PNG, WAV, JSON and TXT under
  `godot/content` needs a `keep` sidecar, so run `python tools/sidecars.py` after adding files.
- **Levels:**
  - Stage 1 is hand-written in `content/levels/stage1.txt`.
  - Stages 2–6 are generated by `tools/levels/build_levels.py`; edit the builder, not the
    output.
  - The legend is at the top of `stage1.txt`.
  - Candle drops are listed in reading order.
- **Art:**
  - `tools/art/*.py` paint frames into `art/build/<sheet>/`.
  - `tools/art/asebuild.py all <sheet>` builds `art/<sheet>.aseprite`, then exports the game
    sheet and JSON **from the .aseprite**.
  - The sheets are hero, props, enemies and bosses; `content/art/sheets.json` lists them.
- **Audio:** `tools/audio/music.py` (scores, two arrangements) and `tools/audio/sfx.py`.

## Lessons from building it (measured, 2026-09-28)

- **`draw_texture_rect_region` with a negative-width rect draws nothing** on the
  Compatibility renderer. Every left-facing sprite was invisible. Sheets now carry a mirrored
  copy (`tex_flip`), and flipped frames sample it with a positive rect.
- **`ImageTexture.get_image()` returned the texture's own Image.** `flip_x()` on it mutated
  the original, which made the mirror test compare mirror against mirror. Call
  `.duplicate()` before editing the result.
- **`"bosstrig".begins_with("boss")`** made the invisible trigger hurt the hero. Boss checks use
  the prefix `boss_`.
- **Balance bugs came from the boss bot, not from the maths.** A bot standing on top of a boss
  never lands the whip, because the lash starts 14 px ahead of the hero. Keep the bot's
  spacing rule.

- **A hold keeps gravity** (a protogames standing rule): death, stage clear and block fades
  froze the hero mid-air when started mid-jump. `Game._hold_gravity()` now lets the body land;
  `t_holds_keep_gravity` failed on the old code for all three cases.
